# @review-agent/github

The GitHub adapter of [review-agent](https://github.com/crissmoldovan/review-agent), an AI pull-request reviewer you run inside your own environment: read a pull
request, download its code as an archive with credential files removed, decide what to post, post the summary,
inline comments and a check run or commit status, and keep the re-review marker — or run the whole review, the same
one the App runs, with `prepareReview` and `runReviewSession`.

Every export: [the library reference](https://github.com/crissmoldovan/review-agent/blob/main/docs/library.md).

Apache-2.0.
