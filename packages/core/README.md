# @review-agent/core

The review engine of [review-agent](https://github.com/crissmoldovan/review-agent), an AI pull-request reviewer you run inside your own environment: settings,
review instructions, running Claude Code headless and read-only, findings, the check and re-review passes, the
review record and the secret scan. It knows nothing about GitHub.

How a review works: [How it works](https://github.com/crissmoldovan/review-agent/blob/main/docs/how-it-works.md).
Every export: [the library reference](https://github.com/crissmoldovan/review-agent/blob/main/docs/library.md).
